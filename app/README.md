# Vacation Planner Application

## Purpose of the Application

The Vacation Planner Application is a mobile Android application developed for travelers to organize and manage vacations and excursions. Users can create, edit, update, and delete vacations, add excursions associated with each vacation, set alerts for vacation and excursion dates, and share vacation details.

---

## How to Operate the Application

### Home Screen
- Launch the application.
- The home screen displays a list of saved vacations.
- Select an existing vacation to view or edit details.
- Select **Add Vacation** to create a new vacation.

### Vacation Details
Users can:
- Enter a vacation title
- Enter hotel/accommodation information
- Enter vacation start and end dates
- Save or delete vacation information
- Share vacation details
- Set start and end vacation alerts
- View associated excursions
- Add excursions to a vacation

### Excursion Details
Users can:
- Add excursion title and date
- Save or delete excursions
- Set excursion alerts
- Edit existing excursions

### Validation Features
The application validates:
- Vacation date formatting (`MM/dd/yyyy`)
- Vacation end date must occur after the start date
- Excursion dates must occur during the associated vacation
- Vacations cannot be deleted if excursions are associated

---

## Android Version

This application is deployed for **Android 8.0 (API level 26)** and higher.
